# **App Name**: Firebase Static Deploy

## Core Features:

- Static File Hosting: Serve static files (HTML, CSS, JavaScript) from the 'public' directory.
- Firebase Hosting Configuration: Configure Firebase Hosting using 'firebase.json' and '.firebaserc' for deployment.
- Easy Deployment: Deploy the static site to Firebase Hosting with a simple command.

## Style Guidelines:

- Primary color: Deep sky blue (#00BFFF) to give a modern and fresh feel.
- Background color: Very light gray (#F0F0F0) for a clean and neutral backdrop.
- Accent color: Coral (#FF8071) for interactive elements and call-to-actions.
- Body and headline font: 'Inter' sans-serif for a clean and readable aesthetic. It is appropriate for both headlines and body text.
- Use simple, outline-style icons for a minimalist design.
- Simple and clean layout to focus on content. Use a basic grid system for alignment.
- Subtle animations on page load for a polished user experience.
