## 🛡️ Capítulo 1: A Regra de Ouro da Segurança

**NUNCA apague todas as informações de uma seção.**

Se você quiser substituir o conteúdo de uma seção (como os depoimentos ou a trajetória):
1. **Mantenha** o item antigo (ou um item de teste/fake) lá.
2. **Crie** o novo item real e **Salve**.
3. **Só então** exclua o item antigo.

> **Por que isso?** Algumas seções do site precisam de pelo menos um "pilar" para manter o layout no lugar enquanto você edita. É como trocar o pneu de um carro: você não tira todos os pneus de uma vez, faz um por um.

## ✨ Capítulo 2: As Seções Inteligentes ("Desaparecimento Mágico")

Você deve ter notado que, se não houver nenhum "Serviço" ou "Evento Futuro" cadastrado, essa parte simplesmente não aparece no site.

Isso é **proposital e fantástico**! Isso garante que seu site nunca pareça "em construção" ou abandonado. 
- Se você não tem eventos este mês, a seção descansa. 
- Assim que você cadastrar um novo, ela reaparece automaticamente com um design lindo.

## 🖥️ Capítulo 3: Passo a Passo do Painel Administrativo

### 1. Início (Dashboard)
Ao entrar, você verá o resumo de quantos pacientes, posts e vídeos você tem. É o seu centro de comando.

### 2. Blog (Escritas do Cuidar)
*   **Onde:** Menu "Blog".
*   **Ação:** Clique em "Novo Post".
*   **Campos Importantes:**
    *   **Título:** O nome do seu texto.
    *   **URL (Slug):** O endereço do link (ex: `seu-site.com/blog/nome-do-post`). O sistema cria sozinho!
    *   **Conteúdo:** Use o editor para colocar negritos, links e imagens.
    *   **SEO (Título e Descrição):** Aqui é onde a "mágica" para o Google acontece. Veja o Capítulo 4.
    *   **Imagem de Capa:** Sempre coloque uma imagem bonita.

### 3. Vídeos (Diálogos Abertos)
*   **Onde:** Menu "Vídeos".
*   **Dica:** Basta colar o link do YouTube! O site busca a imagem e os dados do vídeo para você. 
*   **Capa Personalizada:** Se não gostar da capa do YouTube, você pode subir uma foto sua.

### 4. Trajetória (Sua Jornada)
*   **Onde:** Menu "Trajetória".
*   **Cuidado:** Aqui as fotos são horizontais (deitadas). Use fotos que mostrem você em ação ou espaços de atendimento.

### 5. Eventos Futuros (Agenda)
*   **Onde:** Menu "Eventos Futuros".
*   **Uso:** Sempre que tiver uma palestra ou curso, coloque aqui para a seção "reaparecer" na página inicial.

## 🤖 Capítulo 4: Usando o ChatGPT para atrair Pacientes (SEO/AEO)

SEO é o que faz o Google te encontrar. AEO é o que faz as IAs (como o ChatGPT e o Perplexity) te recomendarem.

### Como preencher os campos de SEO?
Em cada post ou vídeo, você verá campos chamados **Meta Title** e **Meta Description**.

1. **Meta Title (Título para o Google):** Deve ter até 60 caracteres. Deve conter a palavra principal (ex: Luto, Psico-oncologia).
2. **Meta Description (Resumo para o Google):** Deve ter até 160 caracteres. É o texto que convence a pessoa a clicar quando ela te vê nos resultados de busca.

### O "Pulo do Gato" com o ChatGPT:
Não quebre a cabeça tentando inventar esses textos. Use o arquivo `Prompt_ChatGPT_SEO.txt` que preparei para você. 
1. Copie o texto do comando.
2. Cole no ChatGPT com o título do seu post.
3. Ele vai te dar as melhores opções de Título e Descrição otimizados.

## 📖 Dicionário Simples para a Lu

*   **Slug:** É o "nome limpo" do link. (Ex: "A importância do luto" vira `a-importancia-do-luto`).
*   **Meta Description:** O "convite" que aparece embaixo do seu site no Google.
*   **Thumbnail:** É a "capa" de um vídeo ou de um post.
*   **Draft (Rascunho):** O conteúdo está salvo, mas ninguém vê no site ainda.
*   **Published (Publicado):** Está ao vivo para o mundo!
